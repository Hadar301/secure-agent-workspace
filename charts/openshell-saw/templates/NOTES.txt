openshell-sandbox "{{ .Values.sandboxName }}" deployed with BOM {{ .Values.bom.metadata.name }}.

The VM installs itself on boot (no SSH, no setup Job):
  saw-install.service  installs the BOM's OpenShell binaries, starts the gateway
  saw-apply.service    applies the SAW-BOM profiles (workspaces, providers, sandboxes)

Follow the installer on the VM's serial console:

  oc -n {{ .Release.Namespace }} logs -f \
    $(oc -n {{ .Release.Namespace }} get pod -l vm.kubevirt.io/name={{ include "openshell-sandbox.fullname" . }} -o name) \
    -c guest-console-log

The root disk is imported or cloned by CDI (no Job):

  oc -n {{ .Release.Namespace }} get dv {{ include "openshell-sandbox.fullname" . }}-root -w

To apply a changed BOM, restart the VM: virtctl restart {{ include "openshell-sandbox.fullname" . }} -n {{ .Release.Namespace }}

Once the installer reports "apply: Done", connect:
{{- if .Values.route.enabled }}

  Gateway URL (get after Route is assigned):

    oc get route {{ include "openshell-sandbox.fullname" . }}-gateway -n {{ .Release.Namespace }} -o jsonpath='https://{.spec.host}'

  Use the OpenShell CLI with your own OIDC login (the in-VM mTLS identity
  is for the installer only):

    openshell --gateway $(oc get route {{ include "openshell-sandbox.fullname" . }}-gateway -n {{ .Release.Namespace }} -o jsonpath='https://{.spec.host}') sandbox list
{{- end }}
{{- if .Values.route.dashboard }}

  Dashboard URL:

    oc get route {{ include "openshell-sandbox.fullname" . }}-dashboard -n {{ .Release.Namespace }} -o jsonpath='https://{.spec.host}'
{{- end }}

  Shell on the VM (debugging). Adds your public key to the
  {{ include "openshell-sandbox.sshKeySecretName" . }} Secret; KubeVirt pushes it into the running VM:

    make openshell-saw-vm-ssh OPENSHELL_SAW_NAME={{ include "openshell-sandbox.fullname" . }} SAW_NS={{ .Release.Namespace }}

  TUI / GUI:

    make tui SANDBOX_NAME={{ .Values.sandboxName }}
    make gui SANDBOX_NAME={{ .Values.sandboxName }}

To tear down:

  helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
